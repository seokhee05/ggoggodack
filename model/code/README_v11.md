# 통합 실행기 v11 (run_v11_integrated.py + v11_logic.py)

## 실행
```
pip install mediapipe==0.10.21   # v15(윗면)와 같은 MediaPipe. 없으면 lite 모델로 자동 대체
python model\code\run_v11_integrated.py "영상경로"
```
결과: `model\result_<영상이름>_v11.mp4`, `.json`

## 체크리스트 (위에서부터 순서대로)
덮개 열림 → 제품 1~3 × (안쪽면 → 힌지 → 해머 → 윗면) → 덮개 닫힘
- 빼먹은 단계는 빨간 X + "검사 누락!" 팝업 3초, 다음 단계는 계속 진행
- 옆면은 화면에서 뺐지만 검출은 계속 함 (제품 넘기기 판단·JSON 기록용)

## 판정 기준 (숫자는 v11_logic.py 맨 위)
| 단계 | 기준 | PPT 대비 |
|---|---|---|
| 덮개 | 그물 면적 처음 2초 기준의 50% 미만 1초 → 열림, 50% 이상 1초 → 닫힘 | 같음 |
| 안쪽면 | inside conf ≥ 0.70, 면적 ≥ 3%, 0.3초 | 같음 (옆면은 해머 뒤에만 인정, 화면 미표시) |
| 힌지 | 망치가 처음 보이기 직전 4초 안에 쥔 손목 왕복 합 0.8초 | 새 기준 |
| 해머 | 2타 (hammer_check 그대로) | 같음 |
| 윗면 | TOP 0.2초 / Review 0.4초 + 장갑 또는 팔 0.2초 (TOP_RELAX=True) | 완화 (PPT는 양손 장갑 + 양팔 연결) |

## 제품 넘기기
- 해머 친 제품에 해머가 또 나옴 / 해머(또는 옆면) 뒤에 안쪽면이 새로 보임 / 윗면까지 끝남 → 다음 제품
- 해머를 빼먹은 제품은 넘어갈 때 그 구간의 힌지·윗면 근거를 인정
