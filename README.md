# 암레스트 실시간 검사 시스템

공장 카메라 영상을 항상 표시하고, 바코드 스캔을 기준으로 박스별 녹화와
검사 행동 판정을 동시에 수행하는 Windows용 프로토타입입니다.

## 최종 운영 흐름

```text
프로그램 실행 → 카메라 상시 표시 → 바코드 스캔
→ 바코드별 영상 녹화 + 실시간 검사
→ 직원 기준영상 순서로 제품 3개 반복 검사
→ 전체 작업 완료 시 자동 저장
→ 다음 바코드 대기
```

작업자는 ROI 사각형을 지정하거나 `C`, `Q` 키를 누르지 않습니다.

## 실제 직원 기준영상 체크리스트

1. 박스 덮개·보호망 열기
2. 제품 1: 들어 올려 외관·흔들림 → Driver Screw 2Point → 뒤집어
   Knob·Hinge 작동 → Damper·Rib·이음부·Gap → 포장·반환
3. 제품 2: 위 작업 반복
4. 제품 3: 위 작업 반복
5. 보호망·덮개 닫기

사진 점검표의 부품명은 검사 목적을 설명하는 참고자료로 사용하고, 프로그램의
진행 순서와 완료 조건은 직원이 정상 작업한 `check.mp4` 영상을 기준으로 합니다.

소리 검사는 별도 마이크를 사용하지 않고 흔들기와 굽힘·펴기 행동 수행 여부로
대체합니다.

## 판정 방식

- MediaPipe Hand Landmarker로 양손 위치를 실시간 추적합니다.
- 손 궤적의 이동 범위, 방향 전환, 양손 거리 변화를 계산합니다.
- Screw 검사는 영상에서 주황색 Driver 신호를 함께 사용합니다.
- 2Point 항목은 서로 분리된 두 번의 행동 신호가 있어야 완료됩니다.
- 강한 Driver 신호가 잘못된 순서에 나오면 즉시 순서 오류를 경고합니다.
- 한 단계가 18초 이상 진행되지 않으면 누락 가능성을 경고합니다.
- 동일한 움직임으로 여러 항목이 동시에 완료되지 않습니다.
- 제품 1을 반환해야 제품 2 검사로 넘어가는 순차 방식입니다.
- 총 17개 세부 행동 완료 시 영상과 결과를 자동 저장합니다.

### 오검출 억제판 변경사항

- MediaPipe가 손을 놓쳤을 때 비닐·옷·제품 움직임을 손으로 대신 사용하던
  프레임 차분 fallback을 제거했습니다.
- 실제로 검출된 손 좌표만 사용하고 최근 좌표의 중앙값으로 흔들림을 줄입니다.
- 손가락 21개 관절을 연결선으로 표시하며, 어깨-팔꿈치-손목 자세 추적으로
  장갑 때문에 손 인식이 끊기는 구간을 보완합니다.
- 이전 단계의 움직임이 다음 단계까지 이어져 중복 통과하지 않도록 단계 완료 시
  동작 창을 초기화합니다.
- 단계별 최소 관찰시간, 손 검출 비율, 이동량과 방향전환 조건을 강화했습니다.
- JSON 체크리스트에 `evidence`와 `confidence`가 함께 기록됩니다.

> 현재 프로그램은 검사 행동 수행 여부를 판단하는 프로토타입입니다. 암레스트의
> 실제 파손, Gap의 실제 수치, Screw 체결 상태 등 제품 자체의 양불량을 판정하는
> 모델은 아닙니다. 현장 영상으로 동작 임계값을 조정하고 검증해야 합니다.

## Windows 설치

프로젝트 폴더에서 `setup.bat`을 실행합니다.

```bat
setup.bat
```

설치되는 항목:

- Python 3.11
- Git
- Visual Studio Code
- Python 가상환경 `.venv`
- OpenCV
- MediaPipe
- Pillow

## 실행

```bat
.venv\Scripts\python.exe factory_app.py
```

프로그램을 실행하면 카메라가 바로 표시됩니다. 입력창에 바코드를 직접 입력하거나
USB 바코드 스캐너로 스캔한 뒤 `Enter`를 누르면 검사가 시작됩니다.

이미 촬영한 영상은 화면 아래의 `저장 영상 검사` 버튼을 누르고 MP4 파일과
제품 번호를 선택하면 분석할 수 있습니다. 원본 영상은 변경하지 않으며 결과는
`results/제품번호_saved_result.json`에 저장됩니다. 노란 원은 MediaPipe가
실제로 손으로 검출한 작업 위치입니다.

실시간 화면을 열지 않고 저장영상 검사만 실행하려면 다음 파일을 더블클릭합니다.

```bat
run_saved_video.bat
```

저장영상 검사는 사용자의 ROI 입력을 요구하지 않습니다. 영상에서 작업대의
암레스트 후보를 자동으로 표시하고 손·팔 동작을 이용한 7단계 행동 검사를
진행합니다. 결과는 `results` 폴더의 JSON에 저장됩니다.

검사 화면 오른쪽에는 직원 기준영상의 현재 단계 주변 체크리스트가 표시되며,
각 항목은 `대기 → 진행 중 → 완료` 상태로 갱신됩니다. 영상 종료 또는 ESC 종료
시 완료되지 않은 항목은 누락으로 결과에 저장됩니다.

검사는 제품별 순차 방식입니다. 제품 1의 검사와 반환이 끝나야 제품 2로
넘어가므로 같은 손동작이 여러 제품의 검사로 중복 인정되지 않습니다. Driver는
주황색 존재 여부뿐 아니라 실제 이동이 있을 때만 Screw 검사 신호로 인정합니다.

노란 원은 이제 MediaPipe가 실제 손으로 확인한 위치에만 표시됩니다. 장갑이나
가림 때문에 손을 찾지 못하면 노란 원이 사라지고 해당 구간은 판정 증거로 쓰지
않습니다.

## 저장 파일

바코드가 `ABC123`이면 다음 파일이 생성됩니다.

```text
recordings/ABC123.mp4
results/ABC123_result.json
```

동일한 바코드가 다시 입력되면 기존 파일을 보호하도록 날짜와 시간이 붙습니다.

결과 JSON에는 다음 항목이 저장됩니다.

- 바코드
- 검사 시작·종료 시각
- 총 검사 시간
- 17개 세부 행동별 PASS/MISSING
- 항목별 완료 시점
- 순서 오류 및 누락 가능성 경고 내역
- 최종 PASS/NG
- 영상 경로

## 파일 구조

```text
ggoggodack/
├── factory_app.py          # 카메라·바코드·GUI·영상 저장
├── inspection_engine.py    # 직원 기준영상 순차 행동 판정 엔진
├── requirements.txt
├── setup.bat
├── README.md
├── recordings/
├── results/
└── models/
```

## 기본 설정

`factory_app.py` 상단:

```python
CAMERA_INDEX = 0
FRAME_WIDTH = 1280
FRAME_HEIGHT = 720
```

`inspection_engine.py`에서 검사 평균시간과 경고 시간을 설정합니다.

```python
InspectionEngine(nominal_seconds=70.0, warning_seconds=18.0)
```

현장 테스트에서 동작이 너무 쉽게 또는 어렵게 감지되면
`inspection_engine.py`의 각 detector 임계값을 조정합니다.
